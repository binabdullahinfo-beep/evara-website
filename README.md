# EVARA Residences — website

Static site (index.html + assets/) for EVARA Residences, Al Maabilah.
Data (units, prices, sales, payments, staff) lives in Supabase project `evara-residences`.
Staff sign in at `/#admin`.

Before public launch: remove `<meta name="robots" content="noindex,nofollow">` from index.html and replace robots.txt with `Allow: /`.
